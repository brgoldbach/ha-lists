# Changelog

## 1.1.3

- In the Home Assistant iOS app, the page no longer stays blank until a tap.

## 1.1.2

- Tap an item's circle to check it off. Tap its text to change it in place: Enter or a tap outside saves, and
  Escape keeps the old text.

## 1.1.1

- A smaller Settings sheet: one line for each setting, and shorter notes. Density's first choice is now called
  Normal.
- With Large text on a phone, pop-ups no longer run past the right edge of the screen.

## 1.1.0

- A Density setting. Compact makes the lists smaller, with smaller text, in rows and in tiles. A row
  shows its name on one line, a tile on up to two.

## 1.0.0

- A **Lists** page in the sidebar, with a colored tile or row for each Home Assistant to-do list.
- Create, rename, and delete Local To-do lists from the page, also from non-admin accounts.
- Add, check off, and remove items. Clear all checked items.
- The first emoji in a list's name is its icon. On a computer, a button searches all emoji.
- A color for each list: 16 presets, or any color from the color picker.
- Categories put lists in sections. Drag lists between sections, and drag sections into order. A category stays, also
  with no lists, until you remove it.
- Hide lists from the page. Drag lists into any order. Home Assistant's built-in Shopping list starts hidden.
- Favorites: tap the star next to ⋯ on a list. Favorites show in a section at the top, for each person, and the
  settings can hide that section. Stars show either way.
- Settings for each person, kept on all their devices: tiles or rows, item order, favorites, text size, and theme.
- Export everything to a JSON file, and import it again. Import skips a list that Home Assistant does not create.
- Changes made elsewhere in Home Assistant show within 3 seconds.
- A self-check of what the app uses in Home Assistant. A problem shows as a Home Assistant notification, a
  banner, and in the log; lists and settings stay safe.
